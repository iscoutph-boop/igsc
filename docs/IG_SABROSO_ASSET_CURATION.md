## Governance rules

- Do not add Drive images without confirming the project association.
- Do not present architectural renders as completed photographs.
- Do not publish low-resolution screenshots as project hero media.
- Do not publish personal client contact details.
- Give each project its own gallery; do not use the previous shared gallery pool.
- Record public-use approval, project name, status, alt text, and source folder for every new image.
